# Fortune telling / 命理与星象

给 DeepSeek Harness 和[人生开图](https://github.com/Stahl-G/rensheng-kaitu)用的插件，把 MBTI、中式命理、西洋星盘和塔罗放在一起。

分两步：

1. **盲读**：只看出生信息和抽到的牌，AI 读不到你的任何开图资料，先给一份解读。
2. **继续讨论**：把排盘与盲评带入开图工作区的新对话，补充问题后再发送，让 Agent 按问题查阅实际资料。

第一版包含八字（含大运）、紫微（含流年）、每日黄历、六爻、塔罗、西洋本命盘与合盘。全部计算由 [taibu-core](https://www.npmjs.com/package/taibu-core) 完成，插件只做 DSH 适配和界面。

出生信息只存在本机，不写进开图工作区，可以一键删除。算出来的内容不直接写进开图的目标、记忆和今天页；用户确认的行动先作为待采纳建议。

> 传统文化与自我反思参考，不是预测。

### 结合近况继续聊

完成一次盲评后，点「结合近况，开新对话」。DSH 插件版在当前开图工作区新建 DSH 对话，
Kaitu 原生模块版回到「问问」的新对话。计算结果、盲评和工作区说明会放进输入框，等你补充问题后自行发送。
原生模块回到「问问」需要支持草稿接收与模块入口的 Kaitu 版本。
不再在命理页选择资料包或生成第二份解读。模型、工具和权限沿用对话所在环境。

旧版已保存的综合解读仍可回看、删除；新对话的历史由 DSH／问问保存。

### MBTI

MBTI 是第一个入口，不需要出生信息。可以自己测、让 AI 猜，或直接填写已知类型。
问卷有 28 题简版和 91 题完整版，答案自动保存在插件本机目录，回来可继续或修改。每次结果保留来源、题库版本和原始答案。
Agent 的 `fortune_mbti` 工具和页面共用测试进度。类型中 X 表示该维度的回答持平。
AI 猜测只参考输入的描述和明确勾选的命盘，全文随猜测存档；要结合开图完整资料，开新对话后自行发送草稿。
单条记录可删除，“删除我的资料”同时删除 MBTI 答案、类型与猜测。计算采用太卜，来源和题目处理见 `THIRD_PARTY_NOTICES.md`。
